06 / AUDIO SONIFICATION AUDIO ENGINE IDLE
Raw bytes are interpreted directly as audio samples, not decoded according to the file format. 16-bit PCM uses little-endian signed samples. Float mode uses little-endian IEEE 754 values. Stereo interprets consecutive samples as alternating left/right channels. Invalid float samples are silenced. Playback is capped at 60 seconds to limit memory usage. Loudness can vary significantly between files, so keep the volume low when testing.
